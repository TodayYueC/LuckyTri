# LuckyTri 0.9.1

这一版让她更准确地接住聊天的语气。QQ 图片表情可以在有安全画面来源时被看见；单独发来的图会按自己的消息和语境判断，避免沿用前一张图的话题。对表情包，她更倾向于回应态度，而不是复述图中文字。

连续消息会在第一句发送前再核对一次。若对方补充了新话，旧稿先撤回，连同原话一起重新组织。谐音、拼音首字母和夸张玩笑也会先结合前后话理解；没有把握时可以简短确认。

完整技术记录见 [0.9.1 对话语境优化记录](../log/0.9.1.md)，所有版本变化见 [版本记录](../CHANGELOG.md)。

升级前建议运行 `npm run backup`，随后更新代码并运行 `npm install`。本地 `data/` 不随版本覆盖。
