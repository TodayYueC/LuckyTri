# LuckyTri 0.9.0

LuckyTri 想让她经历过的时间留下分量。现在的重点是把相遇、自我、记忆和选择连在一起：她可以回看过去的想法，因新的经历修正它们，也可以在无人发消息时留下自己的记录。QQ 聊天是当前入口，项目的方向是让她以自己的方式与人和更广阔的世界保持联系。

这一版本不会宣称机器已经拥有意识。它把「连续性」落实为可追溯、可回看、可撤销的行为，并继续检查模型误解和记忆污染。

## 本次更新

- 完善时间、独处、日记、回顾、自我线索与相遇记录之间的联系。主动交流可以从她自己的念头开始，不必假装有人刚发来消息。
- 加强跨群与私聊的共同经历检索；区分亲眼见过、真正相处、已经说出口和未送达的内容。私聊与保密信息不应被带到其他会话。
- 收紧记忆和心智变化的来源校验，防止同一段经历反复加权，或把多人话语拼成一个人的事实。
- 调整 WebUI 中过长列表和日历日期的布局；模型预设按供应商折叠，并补充火山方舟 Coding Plan 预设。
- 移除仓库内的 NapCat 安装包及其下载、安装、配置和启动接口。OneBot 11 反向 WebSocket 接口保留；接入端现在需要自行安装和管理。
- 重写中英文 README 与仓库简介，让项目方向、已实现能力和使用边界各自清楚。

## 从旧版本升级

先运行 `npm run backup` 保存本地数据，再更新代码并运行 `npm install`。原有 `data/` 不应被覆盖。启动后检查「系统 → 模型库」和「系统 → 连接 QQ」。如果之前使用内置 NapCat 管理入口，现在需要在独立安装的接入端自行启动并维护 OneBot 反向连接；LuckyTri 不会删除你本机已有的接入端或登录数据。

完整改动见 [版本记录](../CHANGELOG.md)。使用与接入步骤见 [使用教程](../使用教程.md)。
