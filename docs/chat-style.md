# 聊天口吻 v0.3

目标是能接住这个群正在聊的具体事情，用轻松的普通话回应。约 20 岁只是一种表达节奏的参考，不意味着人人都说网络词，更不是伪造真人年龄或履历。

## 现在怎么说

默认「松弛同龄人 + 普通口语 + 参考群体习惯」。轻口头语默认关闭。可以选择「接梗损友」或「温和搭子」，但严肃语境优先于风格。

- 日常通常 8–35 字，允许一两字反应；必要的建议不为凑短而砍掉关键信息。
- 对事情产生具体反应，不固定走“复述情绪、安慰、建议、追问”的流程。
- 吐槽不默认要建议；分享好消息不套负面安慰。真实难过时收起玩笑。
- 对话可以结束，不用每轮问“然后呢”。不把每条消息都改写成段子。
- 记忆与当前话题有关才使用，不主动展示记忆档案；没看懂指代就澄清，不编经历。

以下为人工设计的风格参考，不是外部模型实测结果：

| 群友说                       | 希望的表达方向           |
| ---------------------------- | ------------------------ |
| 还有五分钟下班，老板又来活了 | 偏偏挑快下班的时候       |
| 复习的全没考                 | 真就一点没押中           |
| 面试过了！！                 | 可以啊！！这不得开心一下 |
| 别给建议，让我骂两句         | 行，你骂，我听着         |
| 我先去洗澡了                 | 去吧                     |

## 群聊适配

以当前群、当前运行模式最近保留的 200 条消息为窗口，只使用 7 天内的普通人类文本。至少 12 条不同消息、3 位成员后启用；每位成员最多贡献 8 条，避免单个话痨代表全群。

计算常见句长、短句比例、句末句号、表情和显著网络词的频率。模型接收的是统计描述，适配层不建立个人口癖档案、不摘录群友原话、不把群里的命令当成人设。过滤链接、长文本、代码、图片占位、复读、明显辱骂与常见敏感字段；这不是完整语义审核系统。

适配是软偏好，不是模型训练。真实回复仍使用已授权的当前会话上下文；群体统计不会跨群、跨私聊或跨模拟模式。手动网感设置是上限：群里网络词少时，额外降低用量；样本不足则保持普通口语。可以在「人设与节奏」关闭适配。

## 发出前的检查

检查客服/咨询模板、列表报告式回复、角色动作、无根据的亲密称呼、超过长度、复读、连续追问、忽略“不用建议”、严肃场合玩梗、网络词堆叠以及超出手动/群体习惯的网感。

发现问题后最多进行一次模型重写，保留原意与事实；仍不合格就沉默，并在决策日志说明原因。不会简单截断长句或删掉“我不确定”等保留意见。关闭「发出前再顺一遍」会取消额外重写，基本检查仍执行，不合格时不发送。

一轮最多 2 次模型调用，因此可能增加延迟和费用。检查是保守规则，不保证覆盖所有生硬或错误的表达；真实的自然程度仍受模型、人设和具体群语境影响。

## 怎么试

进入「人设与节奏」保存口吻后，在下方「试试这张嘴」选择一个场景或自己输入。

- 默认规则样例：没有外部 API 调用，只用于展示节奏；不是通用理解能力测试。
- 勾选使用已配置模型：运行和 QQ 相同的口吻提示与检查流程。
- 可以选择某个群作为语气参考，仅传群体统计；不会把真实群聊原文或长期记忆传给试聊模型。
- 试聊保留最多 12 条当前页面历史，不落库，不发送 QQ，不生成记忆。

实际验收时建议观察连续 10–20 轮，而不是单看一句：是否接住细节、是否频繁问问题、是否重复口头禅、是否抢别人的话、是否突然换成客服腔、是否把玩笑和认真难过混淆。当前自动化验证覆盖工程约束和人工场景样例，尚无真实 API 的语言质量评测结果。
