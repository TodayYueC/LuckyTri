# 工作室（WebUI）设计与维护

工作室采用桌面优先的卡片布局。紧凑页头显示当前位置，左侧保留六个主要入口；页面直接呈现可用的信息与操作，不设置装饰横幅或全局返回按钮。

## 设计目标

- 统一卡片边界、间距、字号与表单控件；同一行的首页卡片对齐。
- 保留七套心情主题、角色光团与操作时的弹性动效。天空使用轻量 WebP，不运行常驻粒子画布；支持减少动画及系统偏好。
- 主任务使用页签，人物详情、来源、回放、会话设置和新增操作使用弹层。设置、外观和连接状态使用右上角浮层。
- 保留所有业务接口与编辑、历史、撤销、导入导出功能；改变入口不改变已有数据。

## 信息架构

| 主要入口 | 分区与功能                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------- |
| 此刻     | 角色状态、今天动态、期待、最近的话、心事、未读、用量和累计记录                                     |
| 对话     | 会话列表、聊天、模拟、原因与回放；详情与反馈收进侧边弹层                                           |
| 内心     | 自我线索、便签、心情记录与来源撤销                                                                 |
| 生活     | 日程（今日、待办、体验）、日记、约定、创作（作品、持续项目）、回顾（回顾、来路与章节）             |
| 记忆     | 会话记忆、资料库、阅读足迹                                                                         |
| 人际     | 人物、群聊中的样子、账号关系、历史与撤销                                                           |
| 设置浮层 | 天性（设定、成长、作息与预算、提示词）、系统（连接、模型、表情包、语音媒体、运行、数据备份）、插件 |

手机使用同样的六个入口，导航置于底部。点击当前入口不重置分区；返回其他入口会保留本次访问的分区与滚动位置。旧 URL（包括 #time、#life、#spaces、#lab 等）仍有效。

## 首页自定义

“自定义首页”可以显隐卡片、上移／下移卡片以及选择舒适或紧凑间距。设置只保存在当前浏览器的 luckytri-home-layout-v1，刷新后恢复；损坏的设置回退到默认，未知卡片 ID 被忽略，至少保留一张卡片。角色图片与构图控制位于角色卡片的图片菜单中。

## 外观与语言

右上角“外观与语言”包含主题、减少动画、壁纸与中英文切换。默认中文，语言保存在 luckyLocale，同步 html lang；有未保存草稿时切换语言不会重载数据。教程链接随语言变化。

文案以中文原文为键。**她自己的内容不翻译**：她说的话、日记、念头、理由、记忆、人名这类数据，前端放在带 `data-own` 标记的元素里，保持原文。界面可见的服务端文案（错误、就绪检查、标签）在 API 出口处按请求头 `X-LuckyTri-Locale` 翻译，数据库里的内容从不被翻译。

## 布局与滚动所有权

桌面是固定视口的工作台：侧栏、页头、内容舞台。`min-height: 0` 必须贯穿 flex/grid 父层，滚动由最内层内容承接，不让记录数量改变页面高度。

- 对话：消息独立滚动；会话详情和反馈使用侧边弹层，反馈分页，长记录不会拉高页面。
- 列表加表单的页面：列表滚动、表单滚动，保存按钮留在底部操作条。
- 记忆：列表独立滚动，分页展示；新增收进弹层。
- 回放：消息、日志和原始详情各自滚动，长 JSON 不撑开布局。
- 手机：导航在底部，分栏依次堆叠，各长内容面板有明确高度；任何宽度下都不出现横向滚动。

## 实现边界

Vue 3 + Vite + TypeScript，不引入设计系统依赖。

```text
studio-web/src/
  App.vue          启动、权限、SSE 与数据刷新生命周期
  navigation.ts    主要入口与跨旧路由的分区映射
  components/shell/StudioShell.vue  桌面导航、页头浮层、分区与滚动恢复
  components/ui/useModal.ts        弹层栈、焦点循环与 Escape
  pages/now/home-layout.ts         首页卡片偏好与持久化
  router.ts        URL 解析与旧链接映射
  pages.ts         页面加载表
  pages/           每个入口一个目录
  plates/          对服务端接口的请求封装
  stores/          共享状态：studio、presence
  mood/            心情主题与光团状态
  components/      shell · sky · ta（光团）· ui（通用控件）
  i18n/            index.ts（t、N_、localized、locale）· en/（英文词典）
  styles/          tokens · base · themes · studio
```

样式使用明确的 base、components 层级，工作室的布局和设计规范由 studio.css 统一控制；HTML 在加载样式前声明层顺序，避免懒加载组件改变优先级。页面按需加载，最多保留五个常用页面，不在启动时预加载全部页面。

实时消息在你位于底部时跟随新消息；回看旧消息时保持位置。切换会话清空旧视图并校验异步结果所属会话。操作错误统一显示短暂提示，保存失败保留草稿；有未保存草稿时离开页面会先问一句。浏览器原生的确认框和令牌输入都换成了界面内弹窗。

## 验证与发布

- `npm run build:ui`：构建随项目发布的 `public/app`，改动前端后必须重新构建并一起提交。
- `npm run test:ui`：独立的临时数据库、模拟通道，不向真实群发送；覆盖冒烟（会话、模拟消息、记忆、模型、连接 QQ 两种方式、教程页）、小世界（心情主题与夜晚、固定主题、减少动画、星图撤销、人物详情、日记与约定）、导航缓存、时间页、性能与英文界面（中文只允许出现在她自己的内容里）；另含首页自定义、脏草稿保护、弹层键盘操作，以及 28 个分区 × 5 种宽度（1440 / 1024 / 820 / 390 / 320）的溢出检查。
- `node tests/ui/ta.mjs --serve`：打开一个过了三天的示例世界，方便直接看界面。
- 截图只放在被忽略的 `workspace/` 目录，真实聊天截图和配置不得提交。

系统 → 运行开关中的「版本与更新」支持手动检查 npm 最新版本，显示当前版本、上次成功检查与发布说明。五分钟内复用结果，断网时保留上次信息并显示失败。点击「更新并重启」才下载校验、留备份并切换实例，页面显示阶段，重启期间等待连接恢复；重复点击不产生第二次安装。

人际页的「彼此的关系」按账号绑定人或其他机器人，使用主题下拉框设置对象类型、双向称呼、名字与分寸；人物详情显示关系历史。解除关系不删除相处记录。列表摘要按需读取，正文与原有聊天缓存不受影响。
