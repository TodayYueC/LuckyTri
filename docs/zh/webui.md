# 工作室（WebUI）设计与维护

工作室不是「管理后台里的一个标签页」，而是「TA 的小世界」：她是一团会呼吸、会变形、有表情的灵魂光团，住在界面的中心。你在这里看见她、了解她、编写她的天性，也可以撤销她身上不对的变化，但不能替她改写。

## 设计目标

- **她是界面的中心**。界面文案称她为「TA」；光团、天空和动效随她的状态变化，而不是装饰。
- **心情即主题**。雀跃、甜甜、平静、低落、烦躁、困倦、夜晚七套主题，阈值与 `moodLabel()` 一致，所以主题和她说的心情对得上。色板、天空、粒子和动效节奏随心情与作息平滑过渡；睡着后整个界面变成夜晚。
- **每个区域一个场景**：此刻是天空，内心是星空，人际是星系，一生是日记本，时间是工作台，对话是聊天软件，记忆是书架，天性是温室，系统是工作台。
- **看得见来源**：每个变化都能点开看来源、能撤销。界面展示的是她，而不是配置项。
- **克制**：装饰只出现在导航、页头和空状态，不覆盖真实内容。「减少动画」和系统的减少动态效果会关掉粒子和形变；粒子有上限，标签页隐藏时暂停。

## 信息架构

| 分组 | 入口 | 唯一职责 |
| --- | --- | --- |
| TA | 此刻 | 当前的她：心情、在做什么、最近说的话、在等的事、今天的时间线、用量与运行状态 |
| TA | 内心 | 自我线索的星图、便签墙、心情彩带 |
| TA | 人际 | 人物星系、人物详情、她在各群的样子 |
| TA | 一生 | 日记、回顾、我的来路与章节、约定与期待、书架 |
| 日常 | 时间 | 她实际生活的记录：活动、待办、作品库、持续项目、体验 |
| 日常 | 对话 | 会话、实时聊天与「为什么这么说」、反馈、会话设置、模拟、回放 |
| 日常 | 记忆 | 她记得的事、资料书架 |
| 设置 | 天性 | 唯一由你编写的部分：名字、性格、兴趣、边界、底线、作息、每日 Token、试聊 |
| 设置 | 系统 | 连接 QQ（OneBot 11 或官方机器人，二选一）、模型库、运行开关 |

手机上底部是「此刻、对话、内心、一生」，其余入口在「更多」里。旧版的链接（`#her`、`#live`、`#spaces`、`#lab`、`#knowledge`、`#models`、`#connect` 等）会自动跳到新的位置。

## 右上角：语言

右上角的开关在「中文」与「English」之间切换，默认中文，选择记在浏览器的 `localStorage`（`luckyLocale`），并同步 `<html lang>`。有未保存的草稿时切换语言不会重载数据。教程链接按语言指向 `/guide.html` 或 `/guide.en.html`。

文案以中文原文为键。**她自己的内容不翻译**：她说的话、日记、念头、理由、记忆、人名这类数据，前端放在带 `data-own` 标记的元素里，保持原文。界面可见的服务端文案（错误、就绪检查、标签）在 API 出口处按请求头 `X-LuckyTri-Locale` 翻译，数据库里的内容从不被翻译。

## 布局与滚动所有权

桌面是固定视口的工作台：侧栏、页头、内容舞台。`min-height: 0` 必须贯穿 flex/grid 父层，滚动由最内层内容承接，不让记录数量改变页面高度。

- 对话：消息独立滚动；右侧是这个会话，反馈分页，长反馈不会拉高页面。
- 列表加表单的页面：列表滚动、表单滚动，保存按钮留在底部操作条。
- 记忆：列表独立滚动，分页展示；新增收进弹层。
- 回放：消息、日志和原始详情各自滚动，长 JSON 不撑开布局。
- 手机：导航在底部，分栏依次堆叠，各长内容面板有明确高度；任何宽度下都不出现横向滚动。

## 实现边界

Vue 3 + Vite + TypeScript，不引入设计系统依赖。

```text
studio-web/src/
  App.vue          外壳：导航、顶栏（含语言开关）、主题与天空
  router.ts        入口、导航分组、旧链接映射
  pages.ts         页面加载表
  pages/           每个入口一个目录
  plates/          对服务端接口的请求封装
  stores/          共享状态：studio、presence
  mood/            心情主题与光团状态
  components/      shell · sky · ta（光团）· ui（通用控件）
  i18n/            index.ts（t、N_、localized、locale）· en/（英文词典）
  styles/          tokens · base · themes
```

实时消息在你位于底部时跟随新消息；回看旧消息时保持位置。切换会话清空旧视图并校验异步结果所属会话。操作错误统一显示短暂提示，保存失败保留草稿；有未保存草稿时离开页面会先问一句。浏览器原生的确认框和令牌输入都换成了界面内弹窗。

## 验证与发布

- `npm run build:ui`：构建随项目发布的 `public/app`，改动前端后必须重新构建并一起提交。
- `npm run test:ui`：独立的临时数据库、模拟通道，不向真实群发送；覆盖冒烟（会话、模拟消息、记忆、模型、连接 QQ 两种方式、教程页）、小世界（心情主题与夜晚、固定主题、减少动画、星图撤销、人物详情、日记与约定）、导航缓存、时间页、性能与英文界面（中文只允许出现在她自己的内容里）；宽度覆盖 1440 / 820 / 390。
- `node tests/ui/ta.mjs --serve`：打开一个过了三天的示例世界，方便直接看界面。
- 截图只放在被忽略的 `workspace/` 目录，真实聊天截图和配置不得提交。

系统 → 运行开关中的「版本与更新」支持手动检查 npm 最新版本，显示当前版本、上次成功检查与发布说明。五分钟内复用结果，断网时保留上次信息并显示失败。点击「更新并重启」才下载校验、留备份并切换实例，页面显示阶段，重启期间等待连接恢复；重复点击不产生第二次安装。

人际页的「彼此的关系」按账号绑定人或其他机器人，使用主题下拉框设置对象类型、双向称呼、名字与分寸；人物详情显示关系历史。解除关系不删除相处记录。列表摘要按需读取，正文与原有聊天缓存不受影响。
