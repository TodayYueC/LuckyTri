# 版本记录

## 1.0.9 — 2026-10-11

- 连续追问只回答新问的细节，不反复重讲已经交代的限制；问来源就说来源，问感受就说感受。
- 聊别人提出的项目时只依据原话，不擅自补出对方正在做的玩法或作业背景。机器人交来新正文或提出新问题却被初稿漏接时，按新内容重答一次；单纯重复确认仍然收住。
- 对具体故事片段先讲清眼前发生了什么，再说明整部主线未知；不以等全文为由漏答。
- 拒绝模型输出中的重复 JSON 字段，避免后一个 `bubbles` 静默覆盖完整答案。排队中的消息可以看到本轮开始前已送达的回复，减少重复认错与确认。
- 区分提问、提议、感受和纠正；复核时保留必要的原话与参与者，核对新提议是否被误当成改编旧作、已经听懂的内容是否被再次认错。新问题省略作品名时，可用同一会话中刚送达给同一人的上一条回复找回阅读记录，只带回阅读事实，不带入回复正文。旧总结按当前话题召回，称呼约定独立保留。
- 机器人之间的重复报备与换词确认在形成情感变化前核对。主动草稿声称的新行动也先核实实际记录，旧愿望不能给自己作证；复审保留历史与可读的来源日期。
- 修订保留此前指出的约束；末尾气泡出错时，只有重新通过全部检查的完整前缀才可保留。历史评测隔离未来记忆与自我反馈，记录代码指纹，漏选指定场景时明确报错。
- 移除已不可用的 OpenCode Zen Space Bunny Free 与 Step 5 Preview Free 预设；实例启动时自动删除对应的旧档案，保留其他模型和默认项。
- 新增独立的火山方舟 Agent Plan 分类，提供自动路由与全部 14 个当前文本模型 ID/别名。按官方接口使用专属 `/api/plan/v3` Responses API、模型上下文与视觉能力；不混入 Coding Plan、已启动下线模型或图像、视频、语音和向量模型。

## 1.0.8 — 2026-10-10

- 重新整理对话提示与上下文：优先回答眼前的具体问题、提议和感受，不再让旧活动汇报、群内暗号和过去的自我总结主导普通交流。问候附图同样按当前语境处理，约定称呼仍然保留。
- 修复普通亲近表达被重复检查退回的问题；“我也想你”、晚安等自然回应可以再次使用，无须编出次数、时间间隔或生活建议。完整的一句反应不再因二十字限制被机械改写。
- 多人对话保留实际回应对象与引用证据，不因后面的笑声漏掉认真提问，也不把另一机器人的猜测当本人确认。没有新内容的机器人报备不再形成确认链或关系增长。
- 增加独立的可理解性检查：对方要求解释时，答案须让提问者读懂；修订与事实复核保留当前问题，校验阶段遵循配置的推理程度。
- 作品召回搜索相关历史版本；已有阅读可以核实，不再因近期记录缺失否认过去，也不披露无关私下正文。排除混入游戏资料的无关网页，保留原档案并阻止其成为进度证据或分享内容。
- 区分别人的写作与自己的阅读约定；等待正文时不执行成写作，不拿无关或旧书替代。新保存的念头核对行动与参与者，避免把愿望写成已完成经历。
- 更新中英文 README、能力边界与发布版本徽章；扩展历史回放、连续多人对话和回归测试。聊天记录与模型评测报告只留本地。

## 1.0.0 — 2026-10-04

插件。核心仍然定义她是谁；插件决定她能接触什么世界。

- **Plugin API v1。** 一个插件可以提供通道、感官、有来源的经历、活动素材、她可以选择的行动、书架资料和沙箱页面。它不能替她开口，不能写她的天性、自我、关系或记忆。
- **权限被执行。** 每个插件一个受限进程。没有对应权限就不能读状态、访问网络、注册通道或调用模型。启用时一次同意，升级多要权限时再同意一次。
- **市场与导入。** 工作室可以浏览索引、导入 zip 链接、GitHub 仓库、上传的包或本机目录，核对 sha256，回滚和卸载。她已经经历过的事不随卸载消失。
- **内置插件，默认停用。** 天气。
- **数据库版本 4。** 升级前自动留下快照。没有启用插件时，她的行为与 0.9.9 相同。

## 0.9.9 — 2026-10-02

走向 1.0 之前的最后一次整理：两种连接方式、中英双语、一份重写的文档，以及一个更干净、更容易扩展的仓库。

- **QQ 官方机器人，与 OneBot 11 二选一。** 新增 `server/channels/`：统一的通道契约与 `ChannelHub`，同一时间只启用一个通道，运行中切换无需重启，也可以用 `LUCKYTRI_CHANNEL` 固定。两个通道向核心交出同一种中性消息，注意力、记忆、关系、独处、日记和时间完全共用，区别只在消息怎么到达。官方通道：自动获取并续期访问令牌，连接开放平台网关（心跳、断线恢复、退避重连），转换群 @、群全量、单聊事件并去重，被动回复窗口内按原消息回复、窗口外改发主动消息，记录对方是否关闭主动消息并据此决定能否主动联系，名字与跨群身份的限制写进文档。
- **会话改名。** 官方接口不提供群名，两个通道都可以在「对话」里给会话改名。
- **中英双语。** 右上角可以在「中文」与 English 之间切换，默认中文，选择记在浏览器里。界面全部文案、日期与数字、服务端界面可见的错误与标签都有英文；她说的话、日记、念头和理由不翻译。所有文档中英各一份，文件一一对应，每篇开头有语言切换。
- **不再提及任何第三方接入端。** 系统设置、教程和文档里只保留连接地址与令牌配置信息，不再有任何名称或跳转链接。
- **重写 README 与文档。** 新的 README 讲清项目的主旨、她的一天和核心框架；`docs/zh` 与 `docs/en` 新增架构与扩展点、连接 QQ 的对比、工作室设计，并更新了其余文档。教程页同时生成中文与英文版本，并提供 Markdown 下载。
- **更干净的仓库。** 删除实例的工作记录与一次性修复脚本；测试语料改为合成语句，校验语义不变；`.gitignore` 加固；新增 `tests/repo-hygiene.test.js`，扫描密钥、实例数据、本机路径和第三方接入端名称。版本说明改为概括性的描述，不含运行数据。
- **更清晰的结构。** 存储相关移入 `server/storage/`，就绪检查并入 `server/studio/`，反馈、群体语气和模型预设并入 `server/core/`，「一生」相关模块收进 `server/mind/life/`，评测与审计脚本移到 `scripts/dev/`，浏览器测试移到 `tests/ui/`；`server/version.js` 成为唯一的版本来源，并修正了请求头里过期的版本号。
- **小修。** 下拉选择框的占位与空状态文案可翻译。

## 0.9.1 — 2026-09-29

- **表情包按语气理解。** 有可用画面的表情可以进入视觉，普通表情的文字标签也进入语境。她先判断是在接梗、吐槽还是开启新话题，不再认真复述图中文字。
- **新图按自己的消息判断。** 选择性视觉只取当前、明确引用或紧挨着的同一人图片；可缓存的视觉观察只保留画面事实。
- **连发消息在首句发出前合并。** 发送前增加短暂复查；对方补充新话时撤销旧稿，原话与新话一起重新组织。危机回复不等待。
- **先从上下文解谐音和缩写。** 没把握时简短确认，不突然说教或解释笑点。
- **正在为自己而活的那一件更稳。** 同一愿望换一种说法仍是同一条；被别人的话碰到、她自己说过、写下的念头都会把它留在心上；写下把愿望放下的念头后，不再钉在那一件上；对别人的承诺不再占走这一座。一天结束的快照也会记下那一件。
- **她做过的选择和理由会回到下次相遇。**
- **连续性有了自动备份。** 服务运行时默认每 24 小时在另一个进程里做一份经过完整性检查的备份，只保留最近 7 份；`BACKUP_INTERVAL_HOURS=0` 关闭。
- **模型回复的格式小失误不再丢掉一整轮。** 先尽量修复，修不好再问模型一次。
- **更诚实、更稳的回复。** 没玩过就不说玩过；把自己的话说成对方说的会被退回重写；被问「你怎么知道」时先核对依据，自己先开口的话不能编一条对方发来的消息；复审不再拿天性设定否决她对自己是程序的诚实回答。
- **没人叫她时，话没整理好就不说**，不再用一个字顶替。
- **被直接叫到时模型暂时不可用，稍后自己再试**（30 秒、2 分钟各一次）。
- **独处不再空转。** 只有时间过去、连着空转时，间隔逐次拉长，最长 6 小时；自己的念头连着几条只接上一条时，要接住新东西才留下。
- **记忆与「她是什么样的人」分清。** 话题上的看法不再堆进自我。
- **新增 `npm run audit:sent`**，把她最近发出的回复按今天的检查重放一遍；**新增 `npm run test:clock`**，把真实时钟拨到过去和未来各跑一遍后端测试。回放和试聊不再依赖真实时钟。

## 0.9.0 — 2026-09-28

- **明确项目愿景。** LuckyTri 关注持续的经历、自我与世界的连接，QQ 聊天只是当前入口；中英文 README 同步更新。
- **只保留通用的 OneBot 11 反向 WebSocket 接入。** 系统设置仅显示连接地址与令牌信息；重写 README 和接入教程。
- **注意力认她正在为自己而活的那件事。** 话题碰到 `self.livingFor` 时，她可以因为自己想而接一句，也可以不出声；日记和夜里的回顾能看见这件事，只有真的被碰到才写。
- **相遇留下意义，意志被碰到才算数。** 一次相遇对她意味着什么会回到下次这个人在场时；意义按她过过的日子淡去，淡出后同一个人自己的话才会勾起它。
- **分寸全面收紧。** 私下的话、被要求保密的话，不会通过日记、手记、印象、相遇或回顾进入别的房间；说出去之前会被拦下重写。她不在的会话里路过的话，不会变成她的经历。
- **关系更像真的。** 分清「好久不见」与「人还在眼前、只是没说上话」；同一段经历不会被反复加成亲近；心里的印象不算来往。
- **房间的节奏不是她的样子。** 群里的句长和标点放进 `inner.room`，她按自己的习惯说。
- **注意力、被碰到的次数和久别名单走同一条规则：** 同一个人自己的话对上两个词，一个词组不算，两个人的话不能拼在一起，她自己说过的话也不算。

## 0.8.0 — 2026-09-24 · StartSoul

一个她，由心开口，有自己的日子。

- **统一心智**（`server/mind/`）：版本化的天性、全局心境、跨群一致的关系、从经历里渐进生长的自我线索、她在每个群的面貌、全局手记。所有变化引用来源，可撤销。
- **由心开口**：去掉参与概率、冷却和「被 @ 必回」。每次细看只调用一次模型，同时得到理解、感受、对人的变化、选择、理由和措辞；沉默时心境和关系照样变化。
- **注意力**：确定性的「细看还是扫一眼」，普通群聊只在她在意时调用模型。
- **全局记忆与分寸**：一份记忆服务所有会话，带「公开 / 私下 / 保密」标签。
- **一生**：作息、全局独处、阅读、睡前日记、夜里整理、回顾、可重写的自传、由她自己决定的主动联系。
- **Token 管理**：全局账本、每日上限与后台份额、缓存友好的请求布局。
- 旧人设成为天性第一版，旧数据自动迁移；退役旧的按会话隔离的记忆与概率机制。
