# 版本记录

## 1.3.0 — 2026-10-14

- 新增可选语音输出和语音识别，支持火山语音与 OpenAI 兼容接口。语音默认关闭；她逐句决定是否朗读或唱歌，收到的语音可转成文字，识别失败时继续按文本回退。
- 新增由她选择的互动动作：引用回复、戳一戳、表情回应、骰子、猜拳、撤回自己的上一条、分享音乐、合并转发当前会话消息，以及发送 Markdown 作品；执行前检查渠道能力、目标和频率限制。
- 新增公开网页和 GitHub 仓库链接理解，读取正文或 README；限制请求时间、体积和跳转次数，每一跳都检查内网地址，不携带 Cookie，并缓存结果。
- 新增默认关闭的自动更新。可以定时检查或只提醒；自动安装等待会话空闲，再执行备份、校验、迁移、重启和健康检查，失败时恢复旧版本。
- 贴纸 ZIP 导入改为流式处理，支持 ZIP64 和大型压缩包，并保留嵌套目录分类、进度反馈和结果汇总；异常或超限时清理临时文件并中止请求。
- 改进群聊理解、纠错和复审：减少空泛的保密或图片故障宣告，避免把私聊经历带进无关群；想念时不再自动汇报生活进度，回复优先贴近眼前的话题。
- 扩展 Claude 与 Gemini 模型接入和厂商参数，并改进私聊输入状态、转发消息理解与设置页交互。

## 1.2.4 — 2026-10-13

- 表情库支持一次导入 ZIP 压缩包，可读取多层文件夹、按文件夹归类，跳过重复项、隐藏文件、非图片和超大图片，并汇总导入结果。新表情沿用原有的一次性识别队列，压缩包在内存中处理。
- 修正单一顶层分类目录被误当作压缩包外层目录的问题；像「开心/a.png」这样的目录结构会保留「开心」分类。

## 1.2.3 — 2026-10-13

- 新增表情库：可上传常用表情，由视觉模型整理画面、文字、情绪和适用情境；她只会在合适时选择，并逐渐记住每张表情和具体的人用过后产生的意义。
- 群聊支持真正的 @ 提及。她只能选择近期在群里出现的人；对方刚直接叫她、自然会看到回复时，不重复 @。
- 图片理解默认接收不超过 20 MB 的图片，并在交给模型前压缩到可配置的尺寸和体积；QQ 与管理台新增图片和表情设置，现有 SQLite 数据自动增加所需表结构。

## 1.2.2 — 2026-10-13

- 修复服务器前台守护器漏认记忆迁移阶段而提前启动旧实例的问题。守护器只在更新明确成功、失败或更新进程退出后交接，后续版本新增阶段也会继续等待。
- 更新后正确接管新版实例的进程与停止信号；恢复旧版时及时记录恢复进程，避免交接丢失。
- 迁移中断会保留失败阶段并提示检查与恢复；安装、校验、备份、迁移、启动及恢复失败分别显示具体原因，原始报错留在本机日志中。
- 补充 Node.js/npm 环境检查，以及网络、证书、权限、磁盘和超时错误识别；超时或日志写入失败时先结束子进程，再进入恢复流程。
- 新增真实前台升级与停止交接测试，核验记忆、聊天、关系、配置、知识、日志、备份和插件数据保留。更新中英文 README 与服务器部署说明。

**服务器升级提示：** 1.2.0–1.2.1 点击更新时仍由旧版更新器执行。受影响的前台托管实例应先备份并停止服务，手动执行 `npm install -g luckytri@1.2.2`，再使用同一账号、同一实例目录启动服务。服务管理器的入口使用 `luckytri start --home /原实例目录`，不要删除已有数据或 `runtime/`。详见 [服务器更新](npm-release.md#服务器更新)。

## 1.2.1 — 2026-10-13

- 修正消息分段：回复中的换行按另起一条消息处理，列表仍保留在同一条消息里；续写上文的行会并回去，消息数量遵守当前上限。
- 旧记录中每句话单独换行的回复，在生成上下文和口吻统计里按自然的打字习惯归一，避免她把旧排版继续学成自己的表达。
- 疲惫或紧绷的感受会更充分地影响精力状态；新增 12 组标明为合成数据的表达形态回归场景。

## 1.2.0 — 2026-10-13

- 实例更新新增版本化记忆迁移：先制作并校验整库快照，再用候选版本升级数据库、合并旧版记忆记录并重建全文与经历关联索引；逐表核对持久记录数量，全部通过后才切换版本。迁移失败会恢复快照并重新启动旧版本。迁移不把聊天记忆发送给模型，也不重新生成已有向量。

- 复审提示去掉与前文重复的「认错不加分」条款，同一意思只保留一处，减轻提示膨胀。
- 核对「有没有答到提问的人」时，说明自己不吃饭、没有身体，算作对“吃了什么”的正面回答，不再被当成答非所问而重写。
- 记忆整理和摘要合并与其它机械阶段一样关掉隐藏推理，后台不再为抽事实空转几千推理 token。
- 别人空口说「你搞错了」不再被标成必须认错的纠正场合；只有针对表达方式的批评（人机、重复、不自然等）才走那条短认路径，且先核对是不是真说错了。
- 长对话里从窗口外找回的相关原文会去掉近重复，并最多带五条，避免八条几乎一样的旧句占满提示。
- 被人空口说「你记错了」时，复述自己刚说过的依据不再被当成换词重复而连改两次；每一轮发给模型的 exchange 也不再附带与 current 重复的 humanMessages。
- 关于同一个人的两个说法对不上、又定不下哪个成立时，她想起其中一条，会同时看到另一条以及什么时候、在哪听到的，不再把其中一个当成定论。受限的那条只提示“另有说法”，不复述内容。
- 核对“回复有没有答到提问的人”时，会带上提问者自己更早说过的相关原话（最多两条），“刚才说的那个面试是哪天”这类正确回答不再被当成凭空编造而反复重写。
- 回复更快、更省：复审里“有没有答到提问的人”这一项不再带隐藏推理（复审探针上准确率不变，这一项的输出 token 少了约 93%）；主复审保留原来的推理强度，因为关掉之后会放过一次无证据的改口。火山方舟上选“不思考”或机械整理阶段，现在真正关闭思考，而不是“最低推理”；不支持关闭的模型（GLM）照旧，个别模型拒绝时自动退回最低推理。
- 整理记忆时，换了说法但每一句都有出处的经历不再被丢掉（例如“把周末的篮球也推掉了”）；只有一句话的内容仍按原规则核对句尾。
- 每次选择之后发生了什么会被记下：有没有人接话、可能被纠正、沉默后是否又被叫到、管理台反馈，附原始消息。只从记录推导，不调用模型，回合输入不变；体检新增对应指标和抽样。
- 一件事带回她自己的心思时判断更严：只有一个相同的词且不在这件事的标题里，就不算关联。手记和打算写下时立即进入回忆索引。
- 一件事被想起时，带上她自己当时的心思：当时和后来的手记、为它定下的打算，最多两句。关联由已有来源推导，不调用模型，私下的心思不进群。
- 一周以上的时间不再一律说成“很久以前”，改为一周前、两三周前、一个多月前、几个月前、一年多前。
- 撤销记录改用她自己的时钟，和她的其他经历在同一条时间线上。
- 每一轮记下她当时想起了什么（事实、情景、自我线索、念头、约定），永久保存在选择记录里，不进入提示词，回合输入逐字节不变。数据库只新增一列，旧版本可以照常打开。
- 新增 `npm run audit:life -- --db <备份>`：对备份做只读体检，报告她一生记录的完整性和连续性。新增 `npm run evaluate:traits`：脚本模型下的特质探针。
- 文档新增终极愿景，长期演进准则从属于它。
- 向量服务不再默认是豆包：任何 OpenAI 兼容的 `/embeddings` 接口填地址、模型名和密钥即可，火山方舟（含 Agent Plan）是其中一个预设。维度填 0 时所有模型都用自己的长度，`doubao-embedding-vision` 保持 2048，与 1.1.2 相同，已有向量不用重建；真实向量的召回对比里 1024 略差，所以不再默认缩短。服务按 base64 返回向量、各家不同的“批次过大”提示和不带上限的 413 都能处理。

## 1.1.2 — 2026-10-11

- 向量维度不再写成 1024。填 0 时不向接口指定长度，`doubao-embedding-vision` 使用它自己的 2048。已经保存成 1024 的配置需要改回 0 再保存。

## 1.1.1 — 2026-10-11

- 向量服务要填写请求地址和密钥。模型名可以留空，火山方舟地址会用 doubao-embedding-vision。
- 密钥不再使用密码框，避免浏览器把它当成管理台登录而反复要求重新登录。向量服务自己返回的 401 也不会再被当成管理台掉线。

## 1.1.0 — 2026-10-11

- 她在每个房间都是同一个人。最近在别处说过的话会进入当前这一轮，她知道；一般不主动向这里的人提起别的地方的事。眼前就是当时那个人时，可以接着，也可以不提，由她决定。私下原话、保密内容和另一个账号的经历仍然不带过来。
- 每一轮都带着她自己的状态：醒着或困着、精力、心情、正在过的愿望，以及亲近的人。这是给她自己的，不是向眼前的人汇报的清单。
- 记忆改成一份可重建的检索索引：事实、相遇、情景、自我、念头、日记和约定可以按意思、关键词和在场的人一起找。没有向量模型时仍用关键词和近期上下文，对话照常进行。
- 向量服务只需要密钥。地址、模型和 1024 维按对话服务自动选择，请求走单独的车道，不挡回复。
- 一件事从发生到结果记成情景线程。到了跟进时间只作为候选，仍经过原有的主动发言关卡。教训必须来自外部经历，同一段经历只用一次，两条独立经历才算确立。
- 后台失败不再连环重试：对话优先于整理，永久错误会暂停该模型，日程冲突改选最近的空档。数据库结构升到第 5 版，升级前会先复制整份数据。

## 1.0.9 — 2026-10-11

- 连续追问只回答新问的细节，不反复重讲已经交代的限制；问来源就说来源，问感受就说感受。
- 聊别人提出的项目时只依据原话，不擅自补出对方正在做的玩法或作业背景。机器人交来新正文或提出新问题却被初稿漏接时，按新内容重答一次；单纯重复确认仍然收住。
- 对具体故事片段先讲清眼前发生了什么，再说明整部主线未知；不以等全文为由漏答。
- 拒绝模型输出中的重复 JSON 字段，避免后一个 `bubbles` 静默覆盖完整答案。排队中的消息可以看到本轮开始前已送达的回复，减少重复认错与确认。
- 区分提问、提议、感受和纠正；复核时保留必要的原话与参与者，核对新提议是否被误当成改编旧作、已经听懂的内容是否被再次认错。新问题省略作品名时，可用同一会话中刚送达给同一人的上一条回复找回阅读记录，只带回阅读事实，不带入回复正文。旧总结按当前话题召回，称呼约定独立保留。
- 机器人之间的重复报备与换词确认在形成情感变化前核对。主动草稿声称的新行动也先核实实际记录，旧愿望不能给自己作证；复审保留历史与可读的来源日期。
- 修订保留此前指出的约束；末尾气泡出错时，只有重新通过全部检查的完整前缀才可保留。历史评测隔离未来记忆与自我反馈，记录代码指纹，漏选指定场景时明确报错。
- 移除已不可用的 OpenCode Zen Space Bunny Free 与 Step 5 Preview Free 预设；实例启动时自动删除对应的旧档案，保留其他模型和默认项。
- 新增独立的火山方舟 Agent Plan 分类，提供自动路由与全部 14 个当前文本模型 ID/别名。按官方接口使用专属 `/api/plan/v3` Responses API、模型上下文与视觉能力；不混入 Coding Plan、已启动下线模型或图像、视频、语音和向量模型。

## 1.0.8 — 2026-10-10

- 重新整理对话提示与上下文：优先回答眼前的具体问题、提议和感受，不再让旧活动汇报、群内暗号和过去的自我总结主导普通交流。问候附图同样按当前语境处理，约定称呼仍然保留。
- 修复普通亲近表达被重复检查退回的问题；“我也想你”、晚安等自然回应可以再次使用，无须编出次数、时间间隔或生活建议。完整的一句反应不再因二十字限制被机械改写。
- 多人对话保留实际回应对象与引用证据，不因后面的笑声漏掉认真提问，也不把另一机器人的猜测当本人确认。没有新内容的机器人报备不再形成确认链或关系增长。
- 增加独立的可理解性检查：对方要求解释时，答案须让提问者读懂；修订与事实复核保留当前问题，校验阶段遵循配置的推理程度。
- 作品召回搜索相关历史版本；已有阅读可以核实，不再因近期记录缺失否认过去，也不披露无关私下正文。排除混入游戏资料的无关网页，保留原档案并阻止其成为进度证据或分享内容。
- 区分别人的写作与自己的阅读约定；等待正文时不执行成写作，不拿无关或旧书替代。新保存的念头核对行动与参与者，避免把愿望写成已完成经历。
- 更新中英文 README、能力边界与发布版本徽章；扩展历史回放、连续多人对话和回归测试。聊天记录与模型评测报告只留本地。

## 1.0.7 — 2026-10-09

- 调整理解与表达顺序：先核对本轮原话、连续补充、说话人和引用，再决定回应。被纠正时修正具体问题，不用道歉、内心独白或抽象比喻替代答案。
- 临时话题观点不再自动占据长期自我的核心位置；一次回复不形成固定话术习惯。相关旧想法仍可召回，跨群连续记忆、来源和私密范围保留。
- 已知机器人不再参与人类群聊口吻统计；无新内容的机器人确认循环会收住。明确要求停止时不再一边答应闭嘴一边继续建议，新的问题仍能重新回应。
- 修复游戏内容展示抹去来源与不确定性的错误。当前活动和作品片段带回参考阅读与材料来源，模型整理不再被展示层改写为客户端操作或通关。
- 重写针对最新被退回的稿子；重复确认事实不会因去重而被吞掉。旧话矛盾的修复只用于相关追问，不插入无关问答。收尾、未理解问题和危机场景分别处理。
- 增加全量会话分段审阅、历史场景回放与连续对话评测工具。调用模型的检查需显式运行，原始聊天和报告仅留本地，不随发布包分发。

## 1.0.5 — 2026-10-07

- 修复人际关系已绑定却无法在另一段会话中认出对方的问题。聊天、主动表达、独处、日记和回顾从同一份关系记录按名字、账号与称呼召回，不要求关系对象正在说话。
- 区分当前关系、过去看法和自己的感受。旧的否认或玩笑保留在历史中，不能替代更新后的事实；关系相关回复发送前再次核对，保持自己的相处与称呼选择。
- 关系回忆包含真实相处与已发出的定向回复，不把受每日上限约束的情感变化次数误当作聊天次数。检索数量有上限，私下关系和印象继续遵守会话权限。
- 关系修改期间生成的旧反思、日记与回顾不再提交，避免旧认识重新进入当前自我。修复不改写历史、不消耗人格修改机会。

## 1.0.4 — 2026-10-06

- 新增按账号绑定的人际关系，支持人与机器人、妹妹姐姐等双向称呼、自定义关系、名字、缘由、公开范围与变化历史。接入人物识别、回复、独处、日记、主动联系和待办选择；不凭空增加信任或相处经历。
- 修复内置身份规则与回顾提示写死 LuckyTri 的问题。实例使用天性中的名字，旧默认规则自动修正且不消耗修改次数；另一位机器人按独立账号识别。

- 补充关系权限、同名对象、身份、失败恢复、真实安装切换与不同屏幕回归。校验清单先检查文件哈希，再解析数据库，损坏文件不会返回原始 SQLite 结构错误。

## 1.0.3 — 2026-10-06
