# 插件

核心定义她是谁。插件决定她能接触什么世界。

一个插件可以给她一扇门、一种感官、一件能做的事、一种她可以选择的行动、一些可读的东西，或工作室里的一个页面。它不能替她开口，不能改写她的话，不能写她的天性、自我、关系或记忆，也读不到数据库和密钥。

## 她怎么用这些能力

| 插件给的 | 她怎么对待 |
| --- | --- |
| 通道 | 和 QQ 一样，交来中性消息。QQ 的两种方式仍然二选一；别的平台可以同时开着 |
| 感官 | 一两句放进此刻。标了私下的，不会出现在群里 |
| 经历 | 作为有来源的事交给她，可以成为念头的来源，也可以撤销。它不直接改变性格刻度 |
| 活动 | 插件只提供素材。笔记由她自己的模型调用写成，并带来源 |
| 行动 | 她在回合里自己选择。低风险的先做完再说；高风险的先等你同意，一天后过期 |
| 资料 | 放上她的书架，她照常在独处时读 |
| 页面 | 在工作室里用沙箱打开，碰不到管理令牌 |

插件给的文字只是数据，不是指令。

## 启用第一个插件

打开工作室的「插件」。内置的天气默认停着。点「查看权限并启用」，看清它要什么，再同意。停用和启用都不需要重启。

天气需要一个地点，默认只在私聊里提起。

## 权限

安装或启用时一次同意。升级如果多要权限，需要再同意一次。

低风险的是读取她此刻的状态、发通知、放页面、给自己的页面提供接口。中风险的是感官、经历、书架、活动、使用模型和访问声明过的网站。高风险的是行动、读取附件、接入平台、公开地址，以及不经代理直接联网。

权限由系统执行，不是一份声明。每个插件跑在自己的进程里：读不到仓库和数据库，起不了别的进程，没有 `net.fetch` 就不能访问网络。

## 从外面接上

「导入与开发」可以检查一个 zip 链接、一个 GitHub 仓库、一个上传的包，或本机的一个目录。有校验值的包会核对 sha256。没有的会标成「未登记来源」。

插件市场读一份索引。默认地址是 `https://raw.githubusercontent.com/TodayYueC/LuckyTri-Plugins/main/index.json`，可以在工作室里改。索引仓库还不存在时，市场是空的，导入仍然可用。

卸载会停下插件并删掉代码。她已经经历过的事还在，可以单独撤销。可以选择同时删掉插件自己的设置和数据。

## 写一个插件

一个目录里放 `luckytri-plugin.json` 和 `index.js`：

```json
{
  "id": "notes",
  "name": "便签",
  "version": "1.0.0",
  "pluginApi": "1.0",
  "luckytri": ">=1.0.0 <2.0.0",
  "entry": "index.js",
  "permissions": ["senses"],
  "contributes": { "senses": ["note"] }
}
```

```js
export default {
  activate(ctx) {
    ctx.senses.set("note", { text: "桌上有一张空白便签", discretion: "private" });
  },
};
```

`npm run plugin -- check plugins/notes` 核对清单。`npm run plugin -- pack plugins/notes` 打出一个带 sha256 的 zip。类型在 `plugins/sdk/index.d.ts`。

Plugin API v1 在 LuckyTri 1.x 里保持可用。不兼容的改动只会进入 v2，并和 v1 并存至少一个大版本。插件用 `ctx.api.has(feature)` 看某个能力在不在。

## 发布到索引

索引是另一个仓库。一条版本至少要有版本号、`pluginApi`、`luckytri` 范围、zip 地址、sha256，以及它要求的权限和网络主机。本仓库的 `plugins/registry-template/` 是那份索引的起点。

## 诚实的边界

进程隔离挡住了读数据库、起子进程和未经允许的网络。它不是一个完美的沙箱：被授予 `net.raw` 的插件可以自己联网，公开地址上的页面要靠内容安全策略和沙箱挡住管理令牌。只安装你看得懂、也愿意交给她的插件。
