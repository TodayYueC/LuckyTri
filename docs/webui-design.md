# WebUI 设计与维护

界面沿用 Vue 3、Vite 和现有 plates API 层。页面负责交互，plates 负责请求，服务端继续负责会话、模型和记忆规则。

## 信息结构

- 日常使用：总览、实时会话、记忆与知识。
- 角色与行为：人格与口吻、会话管理。
- 系统配置：模型配置、QQ 连接、调试与回放。

每页标题下说明用途。模型分为连接信息、容量与生成、能力三组；人格分为基础、性格、背景和试聊；记忆与文档通过页内切换分开。长记忆列表分批显示并独立滚动，会话支持搜索。

## 视觉与动效

共享样式在 `studio-web/src/styles.css`，壳层、导航和动效偏好在 `App.vue`。主题使用薄荷绿、深绿正文、斜切标记与轨道装饰。过渡优先使用 transform 和 opacity，避免改变布局。自定义指针保留原生输入光标，只在精细指针设备上显示装饰光环。

支持系统减少动画偏好；侧栏可保存本地减少动画选项。添加动画时必须遵守这两个开关。键盘焦点保持可见，装饰元素不可拦截点击。

## 验证

`npm run build:ui` 生成随项目发布的 `public/app`。`npm run test:ui` 使用独立数据库，检查八个页面在 1440 和 390 宽度下的溢出与截图，并执行会话、模型、记忆和回放操作。截图写入被忽略的 `workspace/ui-review`。不要提交真实聊天截图或配置。
