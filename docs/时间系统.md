# 时间系统

“时间”与“对话”“记忆”位于同一级导航。它让聊天间隔、话题降温、过去留下的想法和当前的内部倾向共同参与下一次交流。它保存的是有来源、可修正的短结论，不保存模型隐藏推理，也不把内部状态包装成人类生理经历。

## 使用

1. 打开“时间”，在顶部选择要查看的群聊或私聊。
2. “此刻”展示当前时间阶段、内在天气、注意点、正在降温的话题和过去状态轨迹。
3. 在“独处方式”中开启后台独处，并选择允许记录的会话。默认聊天安静 20 分钟、普通聊天积累 4 条后才考虑回想，同会话通常间隔 60 分钟。
4. 调用次数、Token、单次输入和单次输出默认均为 0：0 表示不限或直接跟随所选模型。所有字段都可自由调整，不再使用旧版本的小额固定上限。
5. 默认不设置休息时段。开始和结束设为相同小时表示全天可独处；也可以自行设置夜间休息。
6. “现在独处一会儿”会立即检查当前会话是否满足安全条件，不会绕过会话暂停、模拟隔离或关闭记忆等边界。

时间理解始终参与正常聊天：给出本地时间、上次对话相距多久，以及自然延续/重新相遇的提示。当前时间和内部记录放在上下文尾部，保留历史前缀的缓存机会。模拟不读取真实手记，回放只读取当时已经产生的记录。

## 内在状态与手记

时间页使用浏览器整页滚动，顶部导航跟随滚动，设置和手记不会被固定一屏的工作区裁切。时间手记中可展开最近的状态轨迹。

“无人说话时，多久重新看看旧想法”默认 24 小时，0 关闭周期回看。开启时间变化后，即使时间阶段不再改变，也能在新的回看窗口重新阅读过去。允许围绕人格兴趣形成喜好、好奇和轻微无聊的注意倾向；没有新信息不会把旧猜测升级为事实，也允许跳过。主动内容可以是共同兴趣的小想法，而不必每次询问事件进展。“两次主动联系至少相隔”默认 24 小时，可改为 0 取消额外间隔；对方未回应上一条主动消息时仍不追发。

每次有意义的独处除了可以留下手记，还会形成一条独立的状态快照：情绪色彩、能量、靠近倾向、当前注意点和一段对自己的简短理解。正常聊天会读取最近状态，让它影响关注重点、温度和延续旧话题的倾向，但不会把这些字段机械念给用户。

时间阶段由真实交流间隔自然变化：仍在对话、留有余韵、各自生活、安静了一阵、偶尔想起、等待重逢。后台只在新消息、待续事项到期或阶段真正变化时值得重新思考，不会在没有变化时无限循环调用模型。

手记包含创建时间、会话、来源消息序号、类型、置信度、重要性、再次回看时间，以及可选的旧手记引用。类型包括“后来想到”“重新理解”“留待以后”“久别想起”。

修正追加保存，不能覆盖旧文；未来回想会优先取到期记录，再读取近期记录。所有手记只是可能错误的观察，不会自动写入人物长期事实。近期重复内容会被丢弃，无新理解允许不写。

页面提供按会话搜索、分页、修正引用、标记“放下”、隐藏/恢复和删除。隐藏记录不参与后续语境；有修正依赖的旧记录只能隐藏，保护连续轨迹。手记不再使用 200 条硬上限，也不会静默清空；界面分页读取，模型只选择最近和到期的相关内容。后台运行日志保留最近记录与实际 Token 使用量。

话题使用时间衰减权重；重复出现、相关手记中的重要性和未完成状态可以延缓降温，但不能令旧话题永远活跃。权重只是模型理解语境的依据，不是强制回复概率。

## 主动交流

默认关闭。开启后，仅向所选且正常启用的会话发送。默认需要至少 36 小时未交流，模型可以提出一条与来源有关的问候草稿，也可以选择没有值得说的内容。

发送前检查：连接在线、非模拟、非休息时间、配置及语境未改变、置信度足够、符合人格、没有重复与索取陪伴话术。每个会话 24 小时至多一次，上一条主动消息没有得到用户回应时不会继续追发。普通聊天的最后一句是机器人回复，不会永久阻止以后的自然重逢。

复用现有 QQ 发件箱和消息持久化。先记录发送尝试再投递，投递不明标为 uncertain，重启不重发。生成期间如果有人发来消息，旧的内部结论和主动草稿会取消。

## 实现与维护

- `server/time/context.js`：数据表、时间阶段、内在状态装配及话题权重。
- `server/time/manager.js`：低频轮询、阶段变化、容量设置、回看、状态轨迹、追加手记和主动发送约束。
- `server/time/api.js`：设置、手记检索和管理、运行记录。
- `studio-web/src/pages/Time.vue`：独立时间工作台。
- `tests/time.test.js`：隔离、取消、预算、修正与主动消息测试。
- `tests/time-ui.mjs`：分页、设置、状态操作和响应式界面测试。

后台每分钟检查一次条件，检查本身不调用模型。模型完成后只保存短结论与统计，不存隐藏思维过程和完整后台 Prompt。所有数据仍在现有 SQLite 数据库中，原有备份流程包含这部分数据。

模型自然度和观察准确性取决于配置的模型。页面显示的是模型返回的实际 Token 统计；配置为 0 时不做本地硬性阻断，供应商自身限制仍然有效。
