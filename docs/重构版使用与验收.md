# LuckyBot 重构版使用与验收

## 启动与入口

继续使用原有一键启动文件，或在项目目录运行 `npm run launch`。打开 http://127.0.0.1:3210/ 。首次启动自动执行增量迁移，原配置、人工记忆、会话开关和现存聊天记录保留。旧版本已经删除的原文无法恢复。

运行总览控制全局启用和模拟模式；群聊管理控制各群、私聊是否参与。QQ 安装和登录沿用侧栏“QQ 连接与安装”。页面打开的是当前 LuckyBot；真实 QQ 消息已经走新核心，旧模拟器仍是兼容引擎，检验新效果请使用“调试与回放”。

## 推荐操作顺序

1. 模型管理：确认 API、模型名、实际 Context Window、输入和输出预算。旧 API 自动继承，不必重填密钥。新增档案后到群聊管理选择。大输出预算供模型 JSON/推理使用，群聊气泡字数单独控制。
2. 视觉能力只在供应商确实支持时勾选。主模型不支持视觉时，可以在群聊管理选择视觉兼容模型。暂时没有真实视觉服务的端到端验收结果，不能把开关本身视为识图成功。
3. 人格管理：保留原人格正文，结构化调整兴趣、边界、温柔和毒舌程度。默认毒舌较低。群人格覆盖使用 JSON，留 `{}` 继承基础人格。
4. 群聊管理：聚合默认 1200ms，持续输入最长等 4000ms。上下文条数 0 表示使用模型预算。可以添加群聊或私聊；“移出面板”是可恢复归档，会停止参与但保留消息、记忆和日志。每批消息先进行完整语境判断：值得插话时直接回复；判定为旁听后才使用会话里的 0–1 参与概率，抽中就强制回复。明确点名、引用自己和私聊直接进入语境判断。
5. 记忆管理：自动提取先成为候选，核实后点“确认 / 保存”才作为稳定事实参与回复。可以锁定、修改、删除、合并并查看来源和版本。旧人工共享记忆继续遵循原范围；新自动记忆按会话隔离。
6. Prompt 管理：各阶段有独立的大编辑器，保存会归档上一版，可恢复。保存影响下一轮，生成中的旧配置回复会取消。
7. 调试与回放：选择会话、加载消息，输入起止序号并回放。查看决策依据、目标消息、最终上下文、请求、原始正文、Token、耗时和回复气泡。消息和决策自动刷新，不需要刷新整页。

## 新核心与数据流

`server/core/` 按职责拆分消息归档、会话聚合、上下文构建、回复对象解析、话题、记忆、人格、视觉、发言决策、回复生成、校验、调度和模型管理。

消息持久化 → 按会话聚合 → 恢复引用 → 按预算构建结构化上下文 → 加载同范围已确认记忆与阶段线索 → 必要时视觉理解 → 独立发言决策 → 按人格生成 → 本地去重及模型自检 → 必要时重写一次 → 检查新消息和配置 → 按气泡投递并记录 QQ 确认。

最近原文永久归档；每约 40 条有效消息追加阶段整理，旧摘要与已确认事实不被覆盖。模型提取需要来源消息和说话人匹配。自动候选不会仅凭模型自报置信度变成人物事实。阶段摘要标明未经核实。

发送按 outbox 记录 pending、sending、confirmed、uncertain、cancelled。发送确认超时不自动重发，重启后不补发旧稿，避免重复刷屏。新消息到达时取消过时回复，纳入下一批重新理解。

## 验收与范围

- `npm test`：88 项测试，含新增的归档、引用重启恢复、聚合、长上下文预算、媒体归属、记忆版本与隔离、多气泡失败和隔离回放测试。
- `npm run test:ui`：界面、模型和人格保存、手机与桌面宽度、OneBot 新消息自动刷新。
- `node scripts/evaluate-core.js`：从生产数据库建立隔离副本，调用现有模型做四类中文语境回放；不会启动 OneBot 或发送 QQ。结果写入 `data/evaluations/latest.json`。会产生实际 API 费用。
- 当前四个真实模型样例：其他人互聊、引用别人保持沉默；明确接话、聚合求安慰选择回复。样例通过不等于所有群聊场景都保证正确。

目前限制：模型适配为 Chat Completions 兼容协议；工具支持是能力标记，尚未执行工具调用。Token 预算使用保守估算而非供应商 tokenizer。回放对选中批次使用当前配置，不加载可变长期记忆，尚不支持完整历史记忆状态重建和自动 A/B 评分。图片使用可访问的 QQ 媒体 URL，过期图片不会凭空恢复。自动长期事实需要人工确认，尚未实现高置信度事实自动晋升与语义冲突合并。QQ 登录页和旧模拟器暂保留兼容入口。

这些限制在界面中有对应提示，不应把本次称为所有长期行为均已验证的最终版。

## 备份

修改前运行 `npm run backup`。数据迁移只新增 core 表，不删除原表。回滚应先停服务，保留当前数据库副本，再恢复配套旧代码与备份数据库；不要在运行中替换 SQLite 文件。
