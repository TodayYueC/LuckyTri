# LuckyTri-Plugins

This folder is the seed for the plugin index repository
`TodayYueC/LuckyTri-Plugins`. Copy it there as the initial commit.

`index.json` lists plugins. A version entry points at a zip and its sha256.
LuckyTri checks both before it asks the owner to accept the plugin's
permissions. See `docs/zh/plugins.md` for the entry shape and how to publish.
